# CHICO NEXUS — Phase 05: immersive command center

Native WebGL renders three metallic 3D toroidal meshes, with perspective and shader lighting, surrounding the existing approved SVG emblem. This is real geometry, not a replacement 3D wolf model. No added dependency or API, no database changes. The login remains CSS/SVG. The dashboard alone opts into the scene. The canvas is decorative, pointer-inert, and only enabled on fine-pointer desktop conditions without reduced-motion/forced-colors preference. 3D toggle appears only after successful initialization; the CSS/SVG scene remains on fallback. Hardware/software caveats, context loss, viewport changes, and background tabs are handled conservatively. Rendering is limited to a 420-pixel maximum edge and at most 24 draws/second; resources released on unmount. These are design bounds, not measured FPS or Core Web Vitals. Tests verify mesh geometry and source contracts; actual browser GPU, appearance, keyboard, mobile, authenticated workflows and performance still require Phase 06 verification. Reference: https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/WebGL_best_practices
